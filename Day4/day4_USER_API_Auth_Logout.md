## 3️⃣ NFR-USER-001. 액세스 토큰 재발급 API

### 1. API 개요

| 항목 | 내용 |
| :--- | :--- |
| API 이름 | 액세스 토큰 재발급 API |
| 설명 | 액세스 토큰이 만료되었을 때 리프레시 토큰으로 새 액세스 토큰을 발급받는다. |
| 엔드포인트(Endpoint) | `/api/v1/users/refresh` |
| 메서드(Method) | `POST` |
| 인증 필요 여부 | 리프레시 토큰 쿠키 필요 |

### 2. 요청(Request)

#### < Headers >

| Key | Value | 설명 |
| :--- | :--- | :--- |
| Cookie | `refresh_token=<JWT>` | 로그인 시 발급된 리프레시 토큰 (브라우저가 자동 전송) |

#### < 본문 필드 >

| 파라미터명 | 타입 | 필수 (Y / N) | 설명 |
| :--- | :--- | :--- | :--- |
| - | - | - | 요청 본문을 사용하지 않음 |

#### < 쿼리 파라미터 >

| 쿼리 파라미터명 | 타입 | 필수 | 설명 |
| :--- | :--- | :--- | :--- |
| 없음 | - | N | 쿼리 파라미터를 사용하지 않음 |

### 3. 응답(Response)

#### < 성공 >

- **200 OK**

```json
{
  "access_token": "string",
  "token_type": "bearer",
  "expires_in": 1800
}
```

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| access_token | string | 새로 발급된 30분짜리 JWT 액세스 토큰 |
| token_type | string | `bearer` |
| expires_in | integer | 만료 시간, 1800초 |

#### < 실패 >

- **401 Unauthorized** (쿠키가 없거나, 리프레시 토큰이 잘못되었거나 만료됨, 토큰의 user_id에 해당하는 유저가 없음)

```json
{
  "detail": "리프레시 토큰이 유효하지 않거나 만료되었습니다. 다시 로그인해주세요."
}
```

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| detail | string | 리프레시 토큰이 만료되었거나 유효하지 않아 다시 로그인이 필요하다는 오류 메시지 |

- **403 Forbidden**

```json
{
  "detail": "비활성화된 사용자입니다."
}
```

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| detail | string | 비활성화된 사용자 계정으로 로그인 시도 시 반환되는 오류 메시지 |

### 4. 비고

- 리프레시 토큰까지 만료되면 클라이언트는 로그인 페이지로 이동시킨다.
- 리프레시 토큰 자체는 이 API에서 새로 발급하지 않는다. (7일 후 재로그인)

## 4️⃣ REQ-USER-003. 로그아웃 API

### 1. API 개요

| 항목 | 내용 |
| :--- | :--- |
| API 이름 | 로그아웃 API |
| 설명 | 로그인한 사용자가 로그아웃한다. 리프레시 토큰 쿠키를 삭제하고, 클라이언트는 로그인 페이지로 이동한다. |
| 엔드포인트(Endpoint) | `/api/v1/users/logout` |
| 메서드(Method) | `POST` |
| 인증 필요 여부 | Y |

### 2. 요청(Request)

#### < Headers >

| Key | Value | 설명 |
| :--- | :--- | :--- |
| Authorization | Bearer `<access_token>` | 로그인한 사용자 확인 |

#### < 본문 필드 >

| 파라미터명 | 타입 | 필수 (Y / N) | 설명 |
| :--- | :--- | :--- | :--- |
| - | - | - | 요청 본문을 사용하지 않음 |

#### < 쿼리 파라미터 >

| 쿼리 파라미터명 | 타입 | 필수 | 설명 |
| :--- | :--- | :--- | :--- |
| 없음 | - | N | 쿼리 파라미터를 사용하지 않음 |

### 3. 응답(Response)

#### < 성공 >

- **204 No Content** (응답 본문 없음)

#### < 응답 Headers >

| Key | 예시 값 | 설명 |
| :--- | :--- | :--- |
| Set-Cookie | `refresh_token=; HttpOnly; Secure; SameSite=Lax; Max-Age=0` | 리프레시 토큰 쿠키 삭제 |

#### < 실패 >

- **401 Unauthorized**, **403 Forbidden** : 공통 오류 (0-6) 참고

### 4. 비고

- 별도의 토큰 저장소를 두지 않으므로, 이미 발급된 액세스 토큰은 만료(최대 30분)까지 서버에서 무효화되지 않는다. 클라이언트가 로그아웃 시 메모리의 액세스 토큰을 삭제한다.
- 로그인 페이지로의 전환은 클라이언트에서 처리한다.
